------------------------------------------------------------------------------------------------------>  LARAVEL <------------------------------------------------------------------------------------------------------
\\ Instalar el proyecto de laravel
----------------------------------> laravel new dev001-api
\\ Configurar la db
----------------------------------> DB_CONNECTION=mysql
----------------------------------> DB_HOST=127.0.0.1
----------------------------------> DB_PORT=3306
----------------------------------> DB_DATABASE=dev001_api
----------------------------------> DB_USERNAME=root
----------------------------------> DB_PASSWORD=
\\ Migramos la base de datos
----------------------------------> php artisan migrate
\\ Instalamos Sactum
----------------------------------> php artisan install:api
\\ Instalamos Spatie
----------------------------------> composer require spatie/laravel-permission


------------------------------------------------------------------------------------------------------>  REACT <------------------------------------------------------------------------------------------------------
\\ Instalar el proyecto de REACT
----------------------------------> npm create vite@latest dev001-web -- --template react
\\ Instalar librerias de Tailwindcss
----------------------------------> npm install tailwindcss @tailwindcss/vite
\\ Instalación de librerias de componentes
----------------------------------> npx shadcn@latest init
\\ Importa mas componentes
----------------------------------> npx shadcn@latest add card input label 
\\ Instalar axios
----------------------------------> npm install axios react-router
